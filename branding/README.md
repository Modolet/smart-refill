# Smart Refill icon

Original project artwork generated with the built-in OpenAI image generation tool. The source image is `icon-source.png`; `icon-512.png` is the publication export, and `../src/main/resources/icon.png` is the 256px JAR export. ImageMagick performed only deterministic resizing. There are no borrowed game or modpack logos. Project artwork is distributed under the project's MIT license.

## Generation prompt

> Use case: logo-brand. Create one original square app icon for an independent Minecraft utility mod named Smart Refill. Asset: CurseForge mod avatar and JAR icon. A crisp, elegant, tactile voxel/isometric mark: a compact stack of three warm sandstone-gold cubes being replenished by one fresh jade/teal cube, with a bold single circular refill arrow wrapping the stack. Dark midnight teal rounded-square background, subtle depth and controlled highlights, premium clean game-utility branding. Strong centered silhouette readable at 32px, generous safe padding, simple geometry, restrained polished 3D/pixel-inspired rendering with sharp edges rather than noisy pixel texture. No letters, no words, no numbers, no watermark. No Minecraft logo, no Creeper, no Better MC marks, no CurseForge or GitHub logos. Original own symbol, not an official game or modpack identity. Deliver 1024x1024 square, opaque background.
